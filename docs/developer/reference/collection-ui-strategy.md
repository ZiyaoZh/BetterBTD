# 收集活动 UI 策略

> [!NOTE]
> 本文是基于 `1920 × 1080` 的内部坐标参考。实际行为以 `CollectionGameUiActionHandler` 和 UI 识别规则为准；游戏更新后需重新采样验证。

以下是收集模式对于游戏 UI 界面的具体策略。

---

**游戏主界面**
点击坐标(960, 940)，目标进入地图搜索界面

**竞赛结果界面**
点击(960, 800)关闭结果

**首领战结果界面**
点击(960, 880)关闭结果

**地图选择界面**
点击(80, 170)，进入地图搜索界面，准备选择专家地图。

**收集活动可领取界面**
点击(960, 680)，打开可领取的宝箱。

**地图搜索界面**
记录结果区域像素后点击用户配置的模式按钮位置：从左到右第一个为(1275, 45)，第二个为(1350, 45)，第三个为(1425, 45)。默认第二个；重试始终使用选定位置，不识别按钮或自动切换位置。收集与金气球各自保存配置，启动任务时通过 `AutoTaskRequest.MapSearchModeButtonPosition` 固定本次运行的选择。检测到基准坐标 `(962,837)` 的像素相对点击前发生变化，即确认模式按钮已生效，直接使用对应区域的地图识别结果，不再额外等待1000毫秒。确认后未明确识别地图时只等待，不再重复点击模式按钮；首次明确识别的地图在本次搜索中保持不变，加载对应绑定脚本后点击(540, 650)进入该地图。暂时识别为 `Unknown` 时保留确认与地图，明确离开搜索界面后清除本次搜索状态，下次搜索重新确认。
此时需要读取收集模式脚本配置文件，加载目标的脚本文件，已获取难度、模式、英雄等信息。

**地图难度选择界面**
如果脚本未加载或模式不匹配，ESC返回；否则，根据预设的难度分别点击(630, 400)、(970, 400)或(1300, 400)选择简单、普通或困难。

**简单模式选择界面**
如果脚本未加载或模式不匹配，角ESC返回；否则，若英雄已选择，则点击脚本指定的模式按钮（通过常量获取坐标），否则点击(100, 1000)进入英雄选择。

**普通模式选择界面**
逻辑与简单模式相同，但需要匹配普通难度，其余操作一致。

**困难模式选择界面**
逻辑与前面相同，匹配困难难度，操作一致。

**英雄选择界面**
如果英雄已选择或脚本未加载，则执行返回。否则，通过图像识别寻找所需英雄位置：没找到则滚动鼠标，（每次向下滚动50格）来继续找。找到后点击该英雄，再依次点击(1120, 620)确认和(80, 55)返回，标记英雄选择完成。

**关卡提示界面**
点击(1140, 730)关闭提示，进入关卡。

**关卡挑战界面（无提示）**
如果脚本未加载，则点击(1600, 40)打开菜单，再点击(850, 850)投降返回。脚本运行分为3个状态，没有开始运行，则开始运行；正在运行或运行已结束，则不动。

**带提示的关卡挑战界面**
点击(960, 760)关闭提示。

**关卡通关界面**
点击(720, 850)正常通关。

**关卡结算界面**
点击(960, 910)进行结算。

**关卡升级界面**
点击(960, 980)确认升级提示。

**关卡失败界面**
停止关卡计时，通过图像识别找到“返回”按钮位置（相关服务已实现）并点击，回到主界面。

**可返回界面**（通用返回处理）
点击左上角(80, 55)执行返回。

**三个宝箱界面**
依次点击左侧(660, 540)、中间(960, 540)、右侧(1260, 540)三个宝箱，每个宝箱点击两次，间隔分别为2000毫秒和1000毫秒，模拟开启全部三个宝箱。

**两个宝箱界面**
依次点击左侧(810, 540)和右侧(1110, 540)各两次，间隔1000毫秒，开启两个宝箱。

**Insta界面**
点击(960, 540)，确认获得Insta猴道具。

**宝箱已开启界面**
点击(960, 1000)关闭宝箱开启结果，继续后续流程。
