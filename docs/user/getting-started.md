# 快速上手

本页帮助你从安装 BetterBTD 开始，完成截图、热键和第一个脚本的验证。

## 系统要求

- Windows 10/11 x64
- 已安装并可正常进入游戏的 BTD6
- [.NET 8 Desktop Runtime x64](https://dotnet.microsoft.com/download/dotnet/8.0)
- 16:9 游戏窗口，推荐 `1920 × 1080`

BetterBTD 的脚本坐标以 `1920 × 1080` 为参考系。程序会按窗口大小换算，但非 16:9 比例仍可能产生偏移。

## 下载与安装

1. 打开 [GitHub Releases](https://github.com/ZiyaoZh/BetterBTD/releases/latest)。
2. 下载 `BetterBTD.Install.exe`。
3. 运行安装程序并按提示完成安装。
4. 如果程序提示缺少 .NET Desktop Runtime，安装上方链接中的 x64 版本后重试。

正式发布包带有更新器。你也可以在应用中检查更新，或重新从 Releases 下载最新版安装包。

## 第一次启动

1. 先启动 BTD6，并停留在主菜单。
2. 启动 BetterBTD。
3. 打开“设置”，选择界面语言和主题。
4. 将“游戏语言”设置为 BTD6 当前使用的语言。
5. 如果修改过 BTD6 热键，打开按键绑定并在 BetterBTD 中同步修改。

游戏语言会影响 OCR 模板选择，热键则直接决定放塔、升级、技能和下一回合等动作是否正确。

## 配置游戏捕获

回到“开始”页，按以下顺序操作：

1. 捕获模式优先选择 `WindowsGraphicsCapture`。
2. 点击“测试图像捕获”，确认预览是正确的 BTD6 窗口。
3. 如果未找到窗口或选错窗口，点击“手动选择窗口”。
4. 截图正常后启动截图器。
5. 只有在 Windows 11 上确实遇到 BitBlt 黑屏或异常时，才启用 Win11 兼容修复并重新测试。

BetterBTD 支持配置游戏路径和联动启动，但排错时仍建议先手动启动 BTD6，再单独验证捕获。

## 选择输入模式

| 模式 | 适合场景 | 额外要求 |
| --- | --- | --- |
| 普通模拟 | 默认选择，适合绝大多数环境 | 无，使用 Windows `SendInput` |
| 硬件模拟 | 普通模拟在特定环境下不稳定时尝试 | 需要安装 Interception 驱动 |

首次使用请保持普通模拟。硬件模拟的安装和回退行为见 [硬件输入模式](hardware-input.md)。

## 检查按键绑定

至少确认以下项目与 BTD6 一致：

- 防御塔和英雄放置热键
- 三路升级热键
- 切换目标与卖出热键
- 技能编号和英雄物品热键
- 快进与发送下一轮热键

热键不一致通常会让脚本持续跑偏，而不是只失败一次。

## 运行第一个脚本

1. 打开“我的脚本”。
2. 导入一个 `.btd` 脚本；旧版 `.btd6` 和 `.btd6s` 也可以导入转换。
3. 检查脚本的地图、难度、模式和英雄。
4. 让游戏进入脚本对应的关卡准备状态。
5. 从脚本库直接运行脚本，观察运行时窗口中的步骤和日志。
6. 单脚本稳定后，再前往“自动任务”配置循环或批量流程。

不要把第一次验证直接放在收集、黑框或奥德赛任务中，否则截图、热键、脚本和导航问题会混在一起。

## 数据与备份

| 数据 | 默认位置 |
| --- | --- |
| 应用配置 | `%LocalAppData%\BetterBTD\appsettings.json` |
| 用户数据根目录 | `<安装目录>\User\` |
| 脚本库 | `<安装目录>\User\MyScripts\` |
| 自动任务识别规则 | `<安装目录>\User\AutoTasks\` |
| 日志 | `<安装目录>\User\Logs\` |

迁移或重装前，请同时备份应用配置和整个 `User` 目录。不要在 BetterBTD 运行时手工移动脚本库文件。

## 常见问题

### 程序找不到游戏窗口

- 确认 BTD6 已启动且窗口未关闭。
- 使用“手动选择窗口”。
- 多开游戏时确认选择的是准备自动化的实例。
- 重新执行截图测试，不要直接启动脚本。

### 截图正常，但脚本操作偏移

- 将游戏窗口改为 16:9，优先使用 `1920 × 1080`。
- 确认 Windows 缩放和游戏窗口在脚本运行期间没有变化。
- 使用编辑器的坐标选择功能重新取点。

### 脚本按错键或没有反应

- 对照 BTD6 检查 BetterBTD 按键绑定。
- 确认目标游戏窗口没有被权限更高的进程隔离。
- 先使用普通输入模式；需要时再测试硬件输入。

### 自动任务启动后提示找不到脚本

- 先在“我的脚本”确认脚本仍为就绪状态。
- 检查任务使用的脚本 ID 或绑定文件。
- 回到单脚本入口验证脚本本身可以运行。

### F10 没有反应

- F10 只在脚本或自动任务运行窗口打开时注册。
- 其他软件可能已占用 F10。
- 可直接使用运行窗口中的开始和停止按钮。

### 需要提交问题

请在 [GitHub Issues](https://github.com/ZiyaoZh/BetterBTD/issues) 中附上程序版本、Windows 版本、分辨率、游戏语言、捕获模式、复现步骤和 `User\Logs\` 中的相关日志。
