# 硬件输入模式

BetterBTD 默认使用 Windows `SendInput` 模拟键盘和鼠标。只有普通模式在你的环境中不稳定时，才建议尝试基于 Interception 驱动的硬件输入模式。

## 两种模式

| 模式 | 驱动 | 行为 |
| --- | --- | --- |
| 普通模拟 | 不需要 | 通过 Windows `SendInput` 发送输入 |
| 硬件模拟 | 需要 Interception | 通过驱动适配层向已识别的键盘和鼠标设备发送输入 |

## 安装前说明

Interception 是独立的第三方驱动项目。请从其 [上游仓库](https://github.com/oblitum/Interception) 获取驱动、阅读安装说明，并确认你理解内核驱动对系统稳定性和安全性的影响。BetterBTD 不负责安装或卸载驱动。

驱动安装通常需要管理员权限，并可能要求重启 Windows。只从可信来源获取驱动文件。

## 启用步骤

1. 按上游说明安装 Interception 驱动并重启系统。
2. 启动 BetterBTD，打开“设置”。
3. 将输入模式切换为硬件模拟。
4. 查看状态说明是否显示已检测到驱动。
5. 实际移动一次鼠标并按一次键盘，让 BetterBTD 识别当前活跃设备。
6. 使用简单脚本验证移动、点击和按键，再启动自动任务。

## 自动回退

如果配置选择了硬件模拟，但运行时没有检测到 Interception 驱动，BetterBTD 会回退到普通模拟，避免脚本完全失去输入能力。设置页的状态提示会说明当前是否检测到驱动。

## 排错

- 驱动不可用：重新检查上游安装步骤和系统重启状态。
- 鼠标或键盘没有响应：先手动操作一次对应设备，再重试脚本。
- 设备选择错误：断开不使用的同类设备，重新启动 BetterBTD 后再识别。
- 系统不稳定：切回普通模拟，并按上游说明卸载驱动。

硬件模拟不会修复脚本坐标、OCR、游戏语言或热键配置问题。切换模式前，应先确认这些基础配置正确。
