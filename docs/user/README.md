# BetterBTD 用户手册

本目录只说明如何安装和使用 BetterBTD，不讨论内部类结构或实现方案。

## 阅读顺序

1. [快速上手](getting-started.md)：下载安装、首次配置、截图测试和常见问题。
2. [脚本与脚本库](scripts.md)：导入、编辑、运行和管理脚本。
3. [自动任务](auto-tasks.md)：配置收集、金气球、黑框、循环刷关、竞速与奥德赛。
4. [硬件输入模式](hardware-input.md)：安装 Interception 驱动后的可选输入方案。

## 使用前提

- Windows 10/11 x64
- 已安装并可正常运行的 BTD6
- 16:9 游戏窗口，推荐 `1920 × 1080`
- BetterBTD 与游戏一致的语言和热键设置

遇到问题时，先回到 [快速上手的排错章节](getting-started.md#常见问题)，并查看安装目录下的 `User\Logs\`。
