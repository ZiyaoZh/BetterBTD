# 自动任务

自动任务会持续识别当前游戏界面，在菜单、关卡和结算页面之间导航，并在进入关卡后启动已绑定的脚本。它比单脚本执行更依赖稳定截图和正确配置。

## 启动前检查

- 截图测试能稳定看到正确的 BTD6 窗口。
- 游戏语言和 BetterBTD 设置一致。
- 游戏热键和 BetterBTD 按键绑定一致。
- 至少有一个脚本已经从“我的脚本”单独运行成功。
- 任务所需脚本处于就绪状态，并已完成绑定。

点击启动后，BetterBTD 会在捕获和执行前逐一检查本次任务范围内全部已配置脚本使用的快捷键。存在未配置项时，任务不会启动，并会引导前往快捷键设置。

自动任务和脚本执行共享捕获与输入资源，同一时间只能运行一个流程。

## 任务类型

| 任务 | 脚本配置方式 | 适合场景 |
| --- | --- | --- |
| 收集活动 | 可视化脚本配置或订阅包 | 按活动地图自动选择并刷取收集物 |
| 金气球 | 金气球绑定文件或订阅包 | 在支持的地图范围内处理金气球任务 |
| 黑框 | 按地图、难度、模式绑定，支持订阅包 | 按队列推进单图或地图分组 |
| 循环刷关 | 一个脚本 ID | 反复运行同一个普通关卡脚本 |
| 竞速 | 一个竞速脚本 ID | 重复运行当前竞速活动脚本 |
| 奥德赛 | 按顺序填写 3 至 5 个脚本 ID | 手动进入活动后自动推进各关 |
| 机器人控制 | 本地 HTTP 监听地址 | 供本机机器人或桥接程序调用注册动作 |

机器人控制接口中的部分游戏动作仍可能返回 `NotImplemented`，具体状态见 [HTTP 协议](../developer/robot-control-http-api.md)。

## 脚本 ID 与绑定文件

脚本 ID 可在“我的脚本”页面复制。不同任务使用两种配置方式：

- 收集活动通过任务页的可视化窗口管理槽位绑定。
- 金气球和黑框使用槽位绑定文件。
- 循环刷关、竞速和奥德赛直接填写脚本 ID。

绑定文件默认位于：

```text
<安装目录>\User\MyScripts\Bindings\collection.json
<安装目录>\User\MyScripts\Bindings\goldballoon.json
<安装目录>\User\MyScripts\Bindings\blackborder.json
```

这些文件是 BetterBTD 的内部持久化格式。配置收集活动时不需要打开或填写 `collection.json`；在任务页点击“配置”，按收集模式和专家地图选择托管脚本即可。

## 订阅包

订阅包同时保存脚本资产和任务槽位绑定，适合：

- 分享整套收集、金气球或黑框脚本
- 备份一组地图配置
- 在多台机器之间迁移任务资源

拿到整包资源时优先使用“导入订阅包”；只有单个 `.btd` 文件时再使用普通脚本导入。

## 通用设置

每个任务都有操作间隔。数值越小速度越快，但画面切换、系统负载或网络延迟会更容易造成误判。首次运行保持默认值；只有确认当前阶段和动作正确但节奏过慢或过快时再调整。

## 收集活动

1. 选择与脚本包匹配的收集变体。
2. 导入订阅包，或点击任务页的“配置”打开收集脚本配置窗口。
3. 在对应收集模式下，为目标专家地图选择托管脚本并保存。
4. 从范围较小、已验证的脚本开始运行。

任务会识别当前活动地图，再根据“收集变体 + 地图”解析脚本。找不到脚本时应先检查绑定，不要只看脚本标签。

## 金气球

1. 准备支持目标地图的脚本。
2. 导入金气球订阅，或配置 `goldballoon.json`。
3. 启动后观察识别出的地图与解析出的脚本。

如果任务跳过某张地图，检查该地图是否有有效绑定、脚本是否仍存在，以及游戏更新后地图模板是否仍能识别。

## 黑框

黑框按地图、难度和模式形成队列。建议逐步扩大范围：

1. 先配置一张地图的少量模式。
2. 验证模式解锁顺序和结算处理。
3. 再覆盖该地图全部模式。
4. 最后扩展到整组地图。

黑框订阅可按新手、中级、高级、专家或单张地图导出。缺少任一目标槽位的脚本时，运行时会停止或跳过，具体原因以运行窗口的动作状态为准。

## 循环刷关

1. 在脚本库复制目标脚本 ID。
2. 粘贴到循环刷关输入框。
3. 启动任务。

这个模式最适合验证一个脚本的长时间稳定性，也是进入复杂自动任务前的推荐压力测试。

## 竞速

竞速任务使用一个脚本 ID。开始前先手动确认当前竞速活动、英雄和脚本前提匹配。竞速界面随活动更新变化较大，任务失败时优先检查当前界面信息、阶段动作状态和脚本步骤。

## 奥德赛

- 按关卡顺序填写 3 至 5 个脚本 ID。
- 前 3 个必填，中间不能留空。
- 当前版本需要先手动进入奥德赛相关流程，再启动任务。
- 各脚本的英雄、地图和模式应与当期奥德赛规则一致。

## 机器人控制

机器人控制任务启动后才会监听本地 HTTP 地址，默认值为 `http://127.0.0.1:18766/`。默认只供本机桥接程序使用，不应直接暴露到公网。

启动后可查询服务状态和已注册动作；动作不会排队，已有动作执行时会返回忙碌状态。协议、路由和返回结构见 [机器人控制 HTTP 协议](../developer/robot-control-http-api.md)。

## 运行窗口与 F10

运行窗口会显示当前任务阶段、当前动作、动作状态和脚本步骤。右侧界面信息仅显示当前界面及其中可读取的业务值，例如关卡内金币、回合、可见升级路径或地图搜索最终确认的地图；导航失败时，动作状态会显示当前重试次数。

窗口打开后会尝试注册全局 F10：

- 未运行时按 F10 开始。
- 运行中按 F10 停止。
- 注册失败时使用窗口按钮，或关闭占用 F10 的其他软件。

## 排错顺序

1. 脚本能否从“我的脚本”单独运行。
2. 脚本 ID 或任务页显示的槽位绑定是否正确。
3. 游戏热键、语言和窗口比例是否一致。
4. 截图测试是否稳定。
5. 当前游戏页面是否满足该任务的启动前提。
6. `User\Logs\` 中第一条识别、导航或脚本错误是什么。

缩小任务范围通常比提高重试次数更有效。黑框先缩到单图，奥德赛先检查第一关，收集和金气球先确认单个地图绑定。
